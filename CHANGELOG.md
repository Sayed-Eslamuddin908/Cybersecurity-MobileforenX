# Changelog

All notable changes to **MobileForenX** are documented in this file.

The format follows a simple release-based changelog.

## [1.0.0] - 2026-09-17

### Added
- Initial public MobileForenX release.
- `mft` one-command launcher.
- Mobile evidence processing workflow.
- Evidence validation and cryptographic hashing workflow.
- Content extraction component.
- Evidence indexing component.
- Evidence browser component.
- Forensic reporting component.
- Root artifact extraction component.
- SQLite-focused forensic processing.
- Supported wireless ADB workflow.
- Security-management component.
- Encryption-related utilities.
- Docker support.
- Project documentation and security guidance.

### Documentation
- Added comprehensive README.
- Added contribution guidelines.
- Added security policy.
- Added MIT license.
- Added Git ignore rules for secrets, logs, evidence, and generated files.
